# diff playground

A minimal browser-based text diff tool. Paste two texts, see the diff instantly.

Built with [Vite](https://vitejs.dev) and [jsdiff](https://www.npmjs.com/package/diff).

## Development

```sh
bun install
bun run dev      # start the Vite dev server
bun run build    # production build into dist/
bun run preview  # serve the production build locally
```
